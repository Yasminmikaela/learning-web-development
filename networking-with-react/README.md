# Exercise: NASA API Fetch

### Task:
Build a React app that gets a daily picture or video from NASA's API. 
The app needs to show a "Loading..." text while it waits for the data. 
It should show an image or a video depending on what NASA sends.

### What I learned:
- How to use `useEffect` to get data from a website (API).
- How to show a loading message while waiting for data.
- How to show different things (images or videos) using `if` statements.
